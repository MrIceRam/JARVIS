<h1 align="center">JARVIS</h1>

Голосовой помощник для бытовых задач под Windows. Слушает микрофон офлайн, принимает катку в Dota 2 и CS2,
открывает сайты, меняет курсор и его размер, а ещё сохраняет настройки перед переустановкой Windows.
На каждую команду отвечает голосом: «Успешно» или «Ошибка» с причиной.

## Установка

Нужен только [uv](https://docs.astral.sh/uv/): он сам скачает Python и все библиотеки.

```
winget install astral-sh.uv
git clone https://github.com/MrIceRam/JARVIS.git
cd JARVIS
uv sync
uv run jarvis setup
```

`jarvis setup` скачивает модель распознавания речи (1,8 ГБ, на диске останется около 1,4 ГБ). Интернет нужен
только при установке и для команд с сайтами.

Джарвис грузит модель за несколько секунд и держит в памяти около 1 ГБ. Когда он готов слушать, звучит звук запуска.

Если после `winget` команда `uv` не находится, открой новый терминал. Вместо `git clone` можно скачать ZIP с GitHub.

Чтобы Джарвис запускался вместе с Windows:

```
uv run jarvis autostart on
```

После переустановки Windows, если проект остался на другом диске, заново выполни `uv sync` и `uv run jarvis autostart on`.

## Голосовые команды

Каждая команда начинается с обращения: **«Джарвис, ...»**.

| Фраза | Что произойдёт |
|---|---|
| прими катку в доте / прими дотку / прими доту | принять катку в Dota 2 |
| прими катку в кс / прими кс / прими контру | принять катку в CS2 |
| открой гугл | открыть Google |
| открой ютуб | открыть YouTube |
| поменяй курсор на доту | пак `dota` |
| поменяй курсор на дарк | пак `durck` |
| поменяй курсор на окси виолет / на виолет / на фиолетовый | пак `oxy-violet` |
| поменяй курсор на маленький | пак `small_edition_dark` |
| поменяй на следующий курсор | следующий пак по кругу |
| поменяй на случайный курсор | случайный пак |
| поменяй размер курсора на семь | размер от одного до пятнадцати, словом |
| поменяй размер курсора на случайный | случайный размер |
| моя дефолтная настройка / мои настройки | вернуть свои настройки: сейчас это размер курсора 4 |

Джарвис слышит любую речь и ищет команду нечётко, поэтому мелкие ошибки распознавания
(«катков» вместо «катку») не мешают. Что именно он услышал, видно в окне в строке `[слышу]`.

## Команды в терминале

```
uv run jarvis                  слушать микрофон
uv run jarvis --text           вводить фразы с клавиатуры, например: джарвис открой гугл
uv run jarvis setup            скачать модель распознавания речи
uv run jarvis autostart on     запускать вместе с Windows (off — выключить)
uv run jarvis cursor [имя]     поставить пак курсоров (без имени — показать список)
uv run jarvis list             что умеет сохранять бэкап
uv run jarvis backup  [имя]    сохранить настройки (без имени — все)
uv run jarvis restore [имя]    вернуть настройки после переустановки
```

В режиме `--text` размер пиши словом, а вместо «моя дефолтная настройка» набирай «моя настройка».

## Бэкап настроек

`jarvis backup` сохраняет курсор, шрифты пользователя и настройки OBS и DaVinci Resolve. Перед восстановлением
закрой OBS и DaVinci Resolve.

Бэкапы лежат в `backup/` (поменять: `--dir` или переменная `JARVIS_BACKUP_DIR`). Эта папка в `.gitignore`:
в настройках OBS хранится ключ стрима, поэтому на GitHub она попасть не должна.

## Разработка

```
src/
  cli.py            команды терминала и главный цикл
  commands.py       все голосовые команды: игры, сайты, курсоры, настройки
  core.py           обращение "Джарвис" и поиск команды по фразе
  voice.py          микрофон (Vosk), ввод с клавиатуры, ответы голосом
  system.py         окна, клавиши, клики, скриншоты, звук, автозапуск
  vision.py         поиск кнопки на скриншоте
  cursors.py        паки и размер курсора
  backup.py         сохранение и восстановление настроек Windows
  paths.py          где лежат модель, звуки, бэкапы
  assets/           звуки и паки курсоров
tests/              тесты
```

### Новая команда

Всё делается в `src/commands.py`: функция и строка внутри `register_all()`.

```python
def do_something() -> None:
    if something_went_wrong:
        raise CommandError("Не смог то-то")   # Джарвис скажет: "Ошибка. Не смог то-то"
    # дошли до конца без ошибки — Джарвис скажет "Успешно"
```

```python
registry.add("something", ["сделай что то", "другая фраза"], do_something)
```

Фразы пиши без слова «Джарвис» и только русскими словами: английских модель не знает, поэтому «гугл», а не «google».
Новая команда заработает после перезапуска Джарвиса.

### Команды uv

```
uv sync              поставить всё по uv.lock: первая команда после клонирования или переустановки Windows
uv run jarvis        запустить из .venv, активировать окружение не нужно
uv add requests      добавить библиотеку: обновит pyproject.toml и uv.lock (убрать: uv remove requests)
uv run pytest        запустить тесты
```

Перед `uv add` и `uv sync` закрой Джарвиса: запущенный `jarvis.exe` занят Windows, и uv может не суметь его заменить.

### Linux

Поддержка неполная: работают распознавание, голос и сайты, а окна, клавиши, курсоры и бэкап рассчитаны на Windows.
Для голоса нужен espeak-ng: `sudo apt install espeak-ng`.
